# Divyanshu Bhartiya

## What I work on

- **Data platforms:** Databricks lakehouse pipelines in Python, SQL and PySpark, bringing several business systems into one daily reporting layer.
- **Data quality:** automated test suites that run after every refresh and check freshness, completeness, uniqueness, referential integrity and accuracy against source.
- **AI agents in production:** agents for document-heavy workflows, plus the testing, risk-tiering and release process they go through before going live.
- **Reporting:** Power BI semantic models used daily by senior leadership.
